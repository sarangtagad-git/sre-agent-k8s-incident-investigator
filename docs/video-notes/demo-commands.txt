SRE AGENT — LIVE DEMO COMMANDS, ALL 10 INCIDENTS
==================================================
Each block: 1) stage the fault  2) run the investigation  3) revert
Run from the repo root, in a WSL terminal, venv active or use .venv/bin/sre-agent.

Clean end-to-end approval demos (proposed fix PASSES the gate — full
propose -> dry-run -> approve -> verify flow on camera):
  bad_config, image_pull, crash_loop, cascade, unschedulable

Gate-rejection demos (proposed fix is REJECTED by validate_remediation —
good for a "the gate said no" segment, not a clean success demo):
  cpu_throttled, oom_killed, network_blocked, wrong_service_selector

node_down has a much larger blast radius (drains a real node, evicts every
pod on it, not just boutique's) — run it alone, deliberately, not back to
back with the others.


1. bad_config
--------------
Stage:
kubectl -n boutique patch deployment/cartservice --type=json -p '[{"op":"add","path":"/spec/template/spec/containers/0/envFrom","value":[{"secretRef":{"name":"nonexistent-sre-eval-secret"}}]}]'

Investigate:
.venv/bin/sre-agent investigate boutique --workload cartservice --alert "cartservice pods stuck, never becoming Ready" --execute --verbose

Revert:
kubectl -n boutique rollout undo deployment/cartservice


2. image_pull

kubectl -n boutique set image deployment/currencyservice '*=nonexistent.invalid/currencyservice:v0-broken-sre-eval'

10. node_down  [!] HIGHER BLAST RADIUS — drains a real node, evicts EVERY pod on
